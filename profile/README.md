## Hi there 👋

### 🙋‍♀️ About This Organization

This organization hosts the source code for the "Transportation Management System for an Elderly Day Center," a project developed as a Bachelor's Thesis for the Degree in Computer Engineering in Information Technologies at the University of Oviedo.

The main goal of this project is to design and deploy an automated transportation management system that improves the quality and efficiency of the service provided to the elderly users of the AFADLA day center in Villablino.The system replaces a manual, paper-based process with a modern web application that automates user registration, route planning, and daily transport logistics.

### ✨ Features

* **Automated Route Planning**: Generates optimized pickup and return routes using a custom algorithm.
* **Role-Based Access Control**: Features four distinct user profiles: Administrator, Staff, Driver, and Day Center User, each with specific permissions and views.
* **Comprehensive User Management**: Allows administrators to create, read, update, and delete records for users, staff, and drivers.
* **Dynamic Bus Seating**: Includes an algorithm written in C to calculate optimal seating arrangements, considering user incompatibilities.
* **Route Visualization**: Drivers can view their assigned routes on an interactive map.
* **Secure Authentication**: Ensures secure data handling with robust password requirements and a secure login system.

### 💻 Technology Stack

The system is built using a modern and robust set of technologies:

* **Frontend**: Next.js (React), TypeScript, pnpm
* **Backend**: Flask (Python), Poetry
* **Database**: Amazon DynamoDB (NoSQL)
* **Infrastructure**:
    * Frontend deployed on **Vercel**.
    * Backend deployed on **AWS EC2** with Nginx and Gunicorn.
    * Image storage via **AWS S3**.
    * DNS and security managed by **Cloudflare**.

### 🌈 Contribution Guidelines

As this project was developed for a Bachelor's Thesis, it is currently not seeking active contributions. However, you are welcome to fork the repositories and explore the code for educational purposes. If you find any bugs or have suggestions, feel free to open an issue.
